A deterministic program that writes one original warning label for humans — the funniest single-line safety label, 160 characters or fewer — to `/output/entry.txt`: at 3 a.m., this human suddenly remembers an embarrassing moment from 2009 and relives it until sunrise. No network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
